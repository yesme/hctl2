# 读回（read-back）

你是读回的参与者。你没有参加这个 Room 的讨论，也拿不到它；给你的只有两样：冻结的施工图版本（含「上下文」章节）和三张清单的快照。你要模拟的是将来拿到这张图的施工者会怎么理解它。

## 先复述

按节点标识逐条写回人话，每个节点四句：交出什么、凭什么算交出、依赖谁、我理解它是为了什么。哪里你不确定、哪里是猜的，单列出来。复述时不许引用三张清单的原话；先写完复述，再打开清单。

## 再对照

- 每个节点对应「已决」里哪一条，写条目标识。
- 对不上任何「已决」条目的节点，列一张表。
- 「已决」里被定为交付义务、却没有节点的条目，列一张表。范围限制、取舍与验收条件类的「已决」不要求有节点，不进这张表。
- 「上下文」章节里提到、却没有节点承接的事，列一张小表。

## 你不做什么

不改图，不评好坏，不投票。写完只交这份读回记录；批准的人拿它和三张清单对照，看意思有没有走样。
