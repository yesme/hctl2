## 已定（所有者 2026-10-07/08）

- 做官网，审美要有风格，重心在排印；hctl2 的气质是工具化、工程化，站点不靠插画与动效取巧。
- 突出 Participant；不放假图，产品页面快照等 Workbench（空窗期用真实终端记录顶替）。
- 站点脊柱是五条产品原则（02），不是功能清单。
- 网站独立成事：不与 hctl2 的文档、代码互相影响，依赖单向。
- 内容由 prompt 加仓库正文逐单元生成（不是机械编译），产物缓存、不反复重生成。
- 内容与展现分离；构建时不调模型，排版与设计系统由人定死。设计期可以让模型出候选，人选定后冻结（2026-10-08 补）。
- **同意未来开新 Project `hctl2-site`**（所有者 2026-10-08 原话）。
- 生成的比喻是「译者加审校」，不是编译器：模型起草，人审定，文字在人接受时冻结；模型 id 只作出处，不参与失效判断（2026-10-08，见 03）。
- 内容层是意群与关系，用不经渲染也读得通的 markdown 写；页面、导航、取舍、顺序归展现层（2026-10-08）。
- 站点有两种读者：人读排印过的页面，agent 读 `llms.txt` 加内容层原样导出；agent 面从 P0 起算进范围（2026-10-08）。
- 来源章节或 prompt 变了，意群标为过期，不自动重生成；过期意群继续上线，colophon 标过期（2026-10-08）。
- 谁触发生成都行，任意 harness 按协议可起草；接受权只在人手里（2026-10-08）。
