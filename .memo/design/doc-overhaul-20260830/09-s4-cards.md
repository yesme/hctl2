## ① 给 GPT-5.6-sol——全文一致性一遍(带预算,唯一会改文件的线)

```
你在 hctl2 仓库工作。先 git fetch 并快进到 origin/main(C5 已合入,基线 v0.15.1),读施工图 README.md(§2 红线)与 02-target-map.md。对全库规范与解释层(docs/design/**、根 README、docs/usage.md、docs/research/README.md)做一次一致性通过,清单写死、不开放探索:
1. 同一概念只在一个权威位置定义,其余是链接或一句话概括(重点抽查五簇交界:设计层引用的 spec 锚点、contract-tests 的十族锚点、来时路新迁入五张表的锚点、研究总表条目索引);
2. 现在时与历史时分开:现行正文无已退场机制的现在时表述,来时路无对现行合同的重定义;
3. 版本戳全库 v0.15.1 一致、专名词形符合总则、实现名不出现在设计层(第一阶段默认实现的既定提法除外);
4. 交叉链接全部可点、无指向已删节(机械检查之外人工抽查跨文件语境是否仍通顺)。
事实、出处、断链问题直接修;任何疑似语义的发现不修,列表(位置|问题|建议)交所有者。不新增概念、禁令、章节;不重写通顺的句子。提 PR(模板三节,"业界方案调研"不适用),附修改清单与疑似语义列表;闸门(②③④ 清单裁决)前不合入。
```
