# Agency 公开端口与独立服务

> 对象：本库第 2 包，基线 main `231b525`，2026-10-03<br>
> 定位：实现证据；不定义新的领域规则。第一方代码沿 Apache-2.0。

## 决定建议

采用已有 Protobuf / tonic 生成链和 SQLite；Agency 是独立可执行文件，不复用控制面的 Store 或命令内核。端口传递精确 JCS 正文字节，派工引用之外不暴露执行体地址。运行时接口先用脚本验证，第 3 包接 Herdr，不在这里另写终端、工作树管理或模型循环。

依据是[演示线开工书第五节](../../../.memo/design/p2-control-20260906/07-demo-kickoff.md#五agency-的定位)和[本地 Agency 参考实现](../../design/delivery.md#本地-agency-参考实现)。Herdr 能承担会话、输入与终端观察，但没有控制面配对、租户、冻结规格与成果保管这四项。整体替换需要给上游补这些功能；本包采用薄服务包装，运行时由下一包直接适配 Herdr。

## 复用边界

| 需求 | 复用 | 第一方仍需写的内容 |
| --- | --- | --- |
| 本机 RPC | [Protobuf 研究](../libs/protobuf-rpc.md#决定建议)：protoc 36.1，prost 0.14.4，tonic 0.14.6 | 配对和派工方法、业务游标、幂等；沿 Buck 原生生成目标 |
| 持久性和排他写者 | 已锁定 rusqlite 0.40.2；Rust 1.98 `File::try_lock` | Agency 自己的租户数据库、待交结果与恢复，不引用控制面表 |
| 终端与会话 | [Herdr](../sdk/herdr.md#决定建议) | 本包只定义内部运行时接口，脚本不声称有 PTY 或 exact attach |
| 连接票据认证 | [RustCrypto HMAC](../libs/hmac.md#决定建议) | 冻结派工、归属、权限、租约、截止与控制面写者代次，Agency 校验 |

## 失败与恢复

接单不等于启动。准备接单返回派工引用；激活才运行。结果精确字节进入 Agency 数据库后可重复交回，确认消息须带同一结果的字节摘要。Agency 重启不能证明脚本还有效时报告无法履约，不自行重跑；已保管结果仍可取。控制面写者接替只更新自己的租户，不封死待交的旧结果。

租户各有独立端口和数据库。服务处理器固定到该租户，业务请求没有可切换的租户字段。脚本环境只给白名单变量与本次交付，不给配对密钥；它是协议测试执行体，不声明操作系统加固或工具直报能力。
