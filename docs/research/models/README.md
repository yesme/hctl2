# models · 判断与短总结用的模型

这个目录收控制面自己调用的判断模型与本地推理，不收 Room 里参与者用的编码代理。用在哪里见[判断点备忘](../../../.memo/design/room-judgment-20261002.md)：机械判断优先，然后 sysone（只出概率、不写字的判断器），然后人。Room 三件轻量活的跨候选对照在 [`../small-brain-engines-20260928.md`](../small-brain-engines-20260928.md)。那一版的样本不能打分，模型只留形状，准确率未实测。

| 文件 | 对象 | 这批的决定 |
| --- | --- | --- |
| [clm-8b.md](./clm-8b.md) | CLM-8B（Contrastive-LM，冻结 Qwen3-8B 加可训练投影头） | 暂缓。开源可自部署、只训小头；要 GPU 常驻 8B 骨干，中文未见评测 |
| [laya.md](./laya.md) | Laya v0.3.23（Convai Innovations，322M / 421M 编码器） | 暂缓。本机 CPU 可跑；零样本弱，要靠微调；关系题与中文是非题是弱项 |
| [jev.md](./jev.md) | TypeSafe Jev 1.13 | 仅参考行为。本目录样本不能打分，准确率未实测。正文会离开本机 |
| [llama-cpp.md](./llama-cpp.md) | llama.cpp `b11222` 的官方命令行 | 运行方式已选这个二进制。两个平台都没有启动过。启用等可打分样本，不进缺省安装包 |
| [qwen2.5.md](./qwen2.5.md) | 通义千问：3.5 的 2B 与 9B 为第一候选，2.5 为后备 | 暂缓。本版只交千问这一族。本目录样本不能打分，缺省不下载 |
| [bge-m3.md](./bge-m3.md) | BAAI bge-m3 嵌入模型 | 暂缓。只适合「像不像」。本目录样本不能打分，缺省不下载 |

三者对照（Jev 的托管接口见 [mu 对象文件](../harness/mu.md#上游与-jev)，本目录的 [jev.md](./jev.md) 记的是同一模型在三件轻量活上的形状）：

| | Jev | CLM-8B | Laya |
| --- | --- | --- | --- |
| 权重 | 不公开，托管 | 开源，Apache-2.0 | 开源，Apache-2.0 |
| 正文出本机 | 是 | 否，自部署 | 否，自部署 |
| 运行 | 托管接口 | GPU 上的 8B 嵌入服务加 CPU 上的头 | CPU（ONNX）或 GPU，322M–421M |
| 可训练 | 否 | 是，只训约 2000 万参数的头 | 是，整模型 RLCD 微调加温度校准 |
| 中文 | 未见评测 | 未见评测 | 有外部评测，多语言检查点简体约 0.65 |
| 题型与接口 | `noul` / `choice` / `score` | 同形，TypeSafe 兼容 | 同形 |

三者题型相同，正好落在「机制先行、模型可换」的同一接口后面。千问是生成模型，bge-m3 是嵌入模型，不在这张表里。机械规则不是模型，不在这里单列。
