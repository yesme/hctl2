## 上游能力

任务书要求按调研时能用的版本钉 revision。2026-09-28 把第一候选写成千问 2.5，那是 2024 年的模型，代表不了当时已经能用的版本。2026-10-02 用 Hugging Face API 复核：Qwen3.5-2B 与 Qwen3.5-9B 都在，许可证都是 Apache-2.0，不设人工审批，提交见文件头。2B 对大约 1B 那一档，9B 对大约 8B 那一档。官方模型卡的流水线标记是 image-text-to-text。本调研只用文字题，视觉不在范围内。

官方路径 `Qwen/Qwen3.5-2B-GGUF` 与 `Qwen/Qwen3.5-9B-GGUF` 这次读取返回 401，文件名和内容标识没有钉住。第三方量化仓库不记进摘要。所以 3.5 目前只能记仓库提交，不能记 GGUF 摘要。千问 2.5 降为「3.5 没有可钉的 GGUF 时的后备」。

2.5 的 1.5B Q4_K_M 文件名 `qwen2.5-1.5b-instruct-q4_k_m.gguf` 在 2026-09-28 能解析到对象存储。文件大小 1117320736 字节。Hugging Face 给出的内容标识是 `6a1a2eb6d15622bf3c96857206351ba97e1af16c30d7a74ee38970e434e9407e`。这是下载前要再核对的摘要，文件没有下载重算。7B 用同样规则拼出的 `qwen2.5-7b-instruct-q4_k_m.gguf` 返回 404，摘要未钉。

同一厂的 Qwen3-1.7B（`70d244cc86cc`）和 Qwen3-8B（`b968826d9c46`）是 3.5 的前一代，2026-10-02 复核过提交和 Apache-2.0。它们不是 2.5 的同一族，也不当作第二族。2026-09-28 读到的 Qwen3-4B-Instruct-2507（`cdbee75f17c0`，GGUF 仓库 `bc640142c66e`）是后一代里的一个尺寸，常规 Q4 文件名当时 404，这次没有再钉。

中文是选千问、不选 Llama 3.2 1B/3B 的原因：Llama 的小模型中文弱。任务书要的「中文强的至少两族」，本版只交千问这一族，记成差异，不补跑。核过仓库现名与许可、但许可不是可自由再分发的标准条款，因此不写成第二族的有：`internlm/internlm2_5-1_8b-chat`（`57dcbc5455bf`）与 `internlm/internlm2_5-7b-chat`（`eb72b541689b`），许可字段都是 other；`zai-org/glm-4-9b-chat`（`bd8234fe5e0c`），许可字段也是 other。没有核中文评测的模型不点名。Gemma 3 4B（`google/gemma-3-4b-it`，2026-09-28 读到的提交 `093f9f388b31`）要人工接受条款，本文也不主张它中文强，不算第二族，只留作对照，不建议做缺省下载。

## 边界与取舍

生成模型能做 C 的短句改写，也能被提示去做是非和五节选择。选择做完必须由控制面检查标签，不能把自由文字直接写进五节。改写必须对照源消息查有没有多出来的说法、有没有把未定写成已定。来源指针仍由组装器按原消息挂上。

2B 更可能装进普通笔记本，9B 更可能把短句写顺。哪个漏选更少，本目录样本不能打分（见对照文件「标注结果，以及这套题为什么不能开跑」）；等有能打分的中文样本再测，不能先猜。
